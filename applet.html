Interactive applet

The code runs in SageMath through SageMathCell, so there is nothing to install; you only need an internet connection. The first run takes a few seconds while the server gets ready.

Quickhull step by step

Press Launch applet to load the controls, set them as you like and press Start. Nothing is computed until you press it, so you can change several controls first.

Point cloud
A random distribution, the worst case of Quickhull, or your own points.
Number of points and seed
The same seed always generates the same cloud.
Points by hand
Only used with «Points entered by hand». Format: [(0, 0), (4, 1), (2, 5)].
Quadrilateral filter
First discards the points inside the quadrilateral of the four extreme points.
Player
After Start, the whole process plays in a loop. Pause stops it; Next draws one step and stops; Previous undoes it. You can also change the speed or drag the bar to any moment. After clicking the drawing, the arrow keys move step by step and the space bar plays or pauses. To try another cloud, change the controls and press Start again.

Quickhull versus Graham

Measures how long both algorithms take on larger and larger clouds. Press Launch applet, choose the parameters and press Run benchmark; each run takes a few seconds.

Point cloud
With the Quickhull worst case, sizes go up to n = 300.
Maximum n
Eight sizes between 100 and this value are measured.
Repetitions
The best time over all repetitions is kept.
Include Quickhull with filter
Adds the version with the quadrilateral filter and the share of points it discards.

The table also checks that the three methods return exactly the same vertices, and the empirical exponent summarises the growth: close to 1 for n log n and to 2 for n².
